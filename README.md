# Power BI Sales Dashboard

## Project Overview

This project demonstrates my practical experience with Power BI for data cleaning, transformation, analysis, and dashboard development.

The dashboard was created using a sales dataset and focuses on presenting business information through interactive visualizations and KPIs.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel

## Work Performed

- Cleaned and transformed the source data using Power Query
- Created relationships between tables
- Created DAX measures for analysis
- Designed interactive dashboards
- Used charts, tables, filters, and KPI cards
- Analyzed sales performance and trends
